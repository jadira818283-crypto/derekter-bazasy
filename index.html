Мақсат — «Мектеп кітапханасы» мысалы арқылы деректер қорын нөлден құрып, SQL сұраныстары қалай жұмыс істейтінін түсіну. Бұл бөлімде әр командаға: не үшін керек → қалай жазылады → қандай нәтиже береді үлгісі қолданылады.

1-ТАРАУ

Деректер қоры: ұғымдар мен қызметтері

Деректер қоры (Database)

Белгілі құрылыммен сақталған ақпарат жиынтығы. Қызметі: деректерді реттеу, іздеу және өзгерту. Мысал: мектеп кітапханасындағы кітаптар тізімі.

ДҚБЖ (DBMS)

Деректер қорын жасайтын және басқаратын бағдарлама. Мысал: MySQL, PostgreSQL. Қызметі: сақтауды, қолжетімділікті және сұраныстарды басқару.

MySQL

Реляциялық ДҚБЖ. Қызметі: өзара байланысқан кестелермен SQL арқылы жұмыс істеу. MySQL — бағдарлама, ал SQL — сұраныстар тілі.

Реляциялық модель

Деректерді жолдар мен бағандардан тұратын кестелерге бөліп сақтау моделі. Мысал: Books және Readers кестелері өзара байланысады.

Салыстыр: Excel-де кесте жасауға болады; MySQL деректер қорында кестелердің типтерін, шектеулерін және байланыстарын басқаруға арналған.

Кесте (Table)

Бір типтегі нысандардың деректерін сақтайды. Мысалы: Books.

Өріс (Field)

Кестенің бағаны. Мысалы: title — кітап атауы.

Жазба (Record)

Бір объектінің мәліметтері тұрған жол. Мысалы: id=2 кітабының бүкіл жолы.

PRIMARY KEY

Жазбаны бірегей анықтайтын кілт. book_id қайталанбайды және NULL болмайды.

Кестеде екі кітаптың атауы бірдей болуы мүмкін. Бірақ book_id әр жазба үшін бірегей болуға тиіс.

4-ТАРАУ · ҚАДАМ 1–3

MySQL-де қор мен кестені құру

Мысал: school_library атты қор және Books атты кесте жасаймыз.

CREATE DATABASE IF NOT EXISTS school_library;
USE school_library;

CREATE TABLE Books (
  book_id INT AUTO_INCREMENT PRIMARY KEY,
  title VARCHAR(100) NOT NULL,
  author VARCHAR(80) NOT NULL,
  price DECIMAL(8,2),
  publish_year INT
);
CREATE DATABASE — жаңа қор жасайды; IF NOT EXISTS — қор бар болса, қайта құруға әрекет жасамайды.
USE school_library; — келесі командалар осы қорға қолданылатынын белгілейді.
CREATE TABLE Books (...) — бағандардың атауы мен деректер типтерін анықтап кесте құрады.
book_id INT AUTO_INCREMENT PRIMARY KEY — әр кітапқа автоматты түрде бірегей бүтін ID береді.
title VARCHAR(100) NOT NULL — кітап атауы 100 таңбаға дейін, NULL болмауы тиіс.
author ..., price ..., publish_year ... — автор, баға және шыққан жылды сақтайды.
Нәтиже: әзірше кесте бос, бірақ оның 5 бағаны мен ережелері дайын. SHOW TABLES; командасы құрылған кесте атауын көрсетеді.

Нәтиже: соңғы сұраныс тек екі бағанды көрсетеді. Кестедегі бастапқы деректер өзгермейді.
6-ТАРАУ

WHERE, ORDER BY, ASC және DESC

SELECT title, price
FROM Books
WHERE price >= 2000
ORDER BY price DESC;
SELECT title, price — атау және баға бағандарын ғана шығарады.
FROM Books — мәліметтер Books кестесінен алынады.
WHERE price >= 2000 — бағасы 2000 немесе одан жоғары кітаптар ғана қалады.
ORDER BY price DESC — баға бойынша кемуден өсуге емес, жоғарыдан төменге сұрыптайды.

ASC — өсу реті (арзандан қымбатқа), DESC — кему реті (қымбаттан арзанға). WHERE деректерді сүзеді, ORDER BY көрсетілу ретін өзгертеді.

7-ТАРАУ

UPDATE және DELETE — өзгерту және өшіру

UPDATE: бір кітаптың бағасын түзету

UPDATE Books
SET price = 2600.00
WHERE book_id = 1;

UPDATE Books — Books кестесін өзгертеміз; SET price = 2600.00 — жаңа баға; WHERE book_id = 1 — тек ID=1 жазбасына қолдану.

DELETE: бір жазбаны өшіру

DELETE FROM Books
WHERE book_id = 2;

DELETE FROM — жазбаны жояды; WHERE қай жазба екенін анықтайды.

Маңызды: UPDATE немесе DELETE командаларын WHERE шартынсыз орындау көптеген немесе барлық жолдарға әсер етуі мүмкін. Алдымен SELECT ... WHERE ... арқылы өзгеретін жазбаларды тексер.

Айырмашылық: DELETE FROM Books WHERE ... — жазбаны өшіреді; DROP TABLE Books; — кестенің өзін жояды.

8-ТАРАУ

Көпкестелі деректер қоры және FOREIGN KEY

Оқырмандар туралы мәліметті әр кітап алғанда қайта жазбау үшін екі бөлек кесте құрамыз.

Readers — оқырмандар

reader_id — PRIMARY KEY; name — оқырман аты.

Borrowings — кітап алу жазбалары

borrow_id — PRIMARY KEY; reader_id — FOREIGN KEY; book_id — кітап сілтемесі.

CREATE TABLE Readers (
  reader_id INT PRIMARY KEY,
  name VARCHAR(80) NOT NULL
);

CREATE TABLE Borrowings (
  borrow_id INT PRIMARY KEY,
  reader_id INT NOT NULL,
  book_id INT NOT NULL,
  FOREIGN KEY (reader_id) REFERENCES Readers(reader_id),
  FOREIGN KEY (book_id) REFERENCES Books(book_id)
);

REFERENCES Readers(reader_id) — Borrowings.reader_id мәні Readers кестесіндегі бар оқырманға сәйкес болу керектігін білдіреді. book_id да Books кестесімен байланысады.

Байланыс түрі — бірге-көп (1:N): бір оқырманның бірнеше кітап алу жазбасы болуы мүмкін. Бірақ әр Borrowings жазбасы бір оқырманды көрсетеді.

9-ТАРАУ

JOIN: кестелерді байланыстырып шығару

Мысалы, оқырман аты және оның алған кітабының атауын қатар көрсету керек.

SELECT Readers.name, Books.title
FROM Borrowings
INNER JOIN Readers
  ON Borrowings.reader_id = Readers.reader_id
INNER JOIN Books
  ON Borrowings.book_id = Books.book_id;
SELECT Readers.name, Books.title — екі кестеден керекті бағандарды таңдау.
FROM Borrowings — кітап алу жазбаларын негізге алу.
INNER JOIN Readers ON ... — бірдей reader_id арқылы оқырман атын қосу.
INNER JOIN Books ON ... — бірдей book_id арқылы кітап атауын қосу.
Нәтиже: тек екі кестенің байланысқан жазбалары ғана шығады; үш кестенің мәліметі бір нәтиже кестесіне жиналады. INNER JOIN сәйкес келмейтін жазбаларды қоспайды.
10-ТАРАУ

Өз бетіңше орында: 3 жаттығу

А деңгейі. Clubs(id, title, room) кестесін құрып, үш үйірме қос. id — PRIMARY KEY.

B деңгейі. Books кестесінен бағасы 2000-нан жоғары кітаптардың атауын бағасы бойынша өсу ретімен көрсет.

C деңгейі. Readers және Borrowings кестелеріндегі оқырман ID-і мен жазбаларын JOIN арқылы біріктір.

Үлгі жауаптарды көру
-- A
CREATE TABLE Clubs (
  id INT PRIMARY KEY,
  title VARCHAR(80) NOT NULL,
  room INT
);
INSERT INTO Clubs VALUES
(1, 'Робототехника', 205),
(2, 'Шахмат', 107),
(3, 'Python', 306);

-- B
SELECT title FROM Books
WHERE price > 2000 ORDER BY price ASC;

-- C
SELECT Readers.name, Borrowings.borrow_id
FROM Readers INNER JOIN Borrowings
ON Readers.reader_id = Borrowings.reader_id;

Оқу материалы туралы

Бұл — 10-сыныпта деректер қоры мен SQL-ді меңгеруге арналған авторлық жинақ. Арман-ПВ, Алматыкітап, Атамұра баспалары сұралған ортақ мазмұн аясындағы түсініктер біріктірілді; барлық баспаның нақты парақтары толық салыстырылған жоқ. SQL синтаксисі MySQL мысалдарына сәйкестендірілді.
